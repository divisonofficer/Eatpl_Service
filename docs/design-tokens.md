# 회식픽 디자인 기반 (design tokens & invariants)

> 스냅샷: 2026-11-11 · 대상: `css/style.css`(621줄) + `js/` UI 레이어.
> 성격: **살아있는 문서** — 디자인 결정/불변식/현황만 기록하고, 리터럴 → 토큰 실제 치환은 별도 슬라이스로.
> 범위를 넘는 것: 기능 동작/데이터 정책(각 모듈 주석·`README.md`가 정본), 특정 디자인 "취향"이 아니라 *코드가 강제 가능한 규칙* 위주.

## 0. 사용법 규칙 (이 문서의 용도)

- 새 UI 코드는 **새 색/크기/간격/모션을 즉석 산출하지 않는다** — 아래 테이블 재사용 또는 먼저 이 문서를 갱신.
- 판정 로직(편의 정보 필터 등)은 **여러 화면이 같은 함수/같은 입력을 공유**한다(현재는 `js/amenities-fmt.js`의 `amenityStates()`가 목록·프리뷰·필터·상세 판정을 단일화 — 디자인이 아니라 이 원칙을 유지).
- 컬럼 "표기"는 코드에 실제로 존재하는 이름/값 기준. 토큰 **키는 있는데 정의 위치/의도가 헷갈리는 것**(하단 ⚠️)은 그대로 기록해 두고 임의로 바꾸지 않는다.

  같은 주황 가족이나 역할이 달라 리터럴 유지.

## 2. 타입·크기·간격 (현행 = 기본값 산발, 토큰화 후보)

- 폰트 스택: `-apple-system, BlinkMacSystemFont, "Apple SD Gothic Neo", "Pretendard", "Noto Sans KR", sans-serif` (한글 폴백 체인 명시 — 유지).
- **베이스 유닛 없음**: 반지름 `4/6/10/12/14/16/18/20/99px` 계열이 자리별로 하드코딩(도입 후보: r-1..r-4 + pill). 높이/패딩/갭도 14/18/20/22px·6/8/12px 등 산발.
- 그림자 2~3단(`--shadow`, `--shadow-sm` + 리터럴 `rgba(...)` 몇 곳), 버튼 높이 40/48/30/36/42px 혼재.
- 다루기 전 "**무슨 결정인지**"부터: 유닛 스냅(4/8 기반?) / 99px pill 통일 / 버튼 높이 표준화 / 그림자 계단 — 취향이 아니라 **일관성 규칙**으로 확정 후 치환.

## 3. 모션 (원칙만 고정)

- 일과성 전환·전개(시트 스냅, 상세 FLIP, 카드 페이드/슬라이드, 핀 등장)는 **감축 대상 아님**(의미 있음).
- 무한 "장식" 루프(핀 할로, 스켈레톤 shimmer)는 **`prefers-reduced-motion: reduce`에서 정지** — 슬라이스1에서 적용 완료(`:mk-halo` 정지·`opacity:0`, `.tile.skel`/`.nb-card.skel` 애니메이션 제거). 로딩 스피너(`spin`)는 상태 표기라 유지.
- JS 모션은 부분 적용 상태: 상세 개폐만 `REDUCE` 확인(js/app.js:730 부근), 나머지 JS 구동 값은 후속 점검.
- 이바리에이트 값(예: `cubic-bezier(.2,.8,.2,1)`)은 여러 곳에 반복 — 토큰화 시 여기 한 곳 정의 후보.

## 4. 상태·접근성 규칙

- `[hidden] { display: none !important; }` — 어떤 display/클래스보다 우선(과거 "숨김인데 보이는" 버그 이후 불변).
- 라이브 리전: 결과 카운트 `#resultCount`(`role="status"`), 토스트(`role="status"`) — 슬라이스1에서 추가. 목록 로딩은 `#results`에 `aria-busy` 토글(js/app.js `run()`).
- 포커스 링: `:focus-visible` 명시 규칙 없음(UA 의존) — **후속 후보**(커스텀 버튼 밀집). 터치 타깃 하한 미지정(현 30~48 혼재) — 후속 후보.
- 이미지 폴백: 상세 갤러리엔 `onerror` 제거 처리 있음; 썸네일/카드엔 없음 — 후속 후보.

## 5. 데이터·표현 불변식 (디자인이 의존하는 경계 — 깨지 말 것)

1. 카카오맵 **장소 사진 스크래핑 금지**(약관·저작권·프록시 고지) — 대체: 다음 이미지 검색 썸네일 + "검색 이미지·실제 매장과 다를 수 있음" + 출처 링크. (근거: `README.md` 사진 섹션, 모델/툴 전반)
2. **`merUrl` 원본 그대로**: 공유 인코딩(`js/share.js`)/iframe 열람/새 창 모두 변형 금지; 공유 링크는 클라이언트 인코딩·서버 저장 없음. (`proxy/eatpl.php` 자체 프록시는 미완 스캐폴드 — `YOUR_ID`.)
3. 매장 사진은 결과 카드 최대 3장·핀 1장(검증분) 등 **캡 상한 존중**.
4. 다른 사이트 브라우저의 `/api/*` 403(`Sec-Fetch-Site`) — 스타일/앵커에도 유사 경계 원칙: 위치정보는 `https`/보안 컨텍스트 요구 시 토스트로 안내(지면 위치 버튼 로직).
5. 색상/문구가 **데이터 상태(예: `fellBack` 모의 폴백 배지)를 대신 말하지 않는다** — 배지·토스트로 명시적으로.
